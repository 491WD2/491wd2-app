# Screenshots folder

Place PNG captures here using filenames from [PAGES_AND_SCREENSHOTS.md](../PAGES_AND_SCREENSHOTS.md).

This folder is copied into the client `handoff/screenshots/` package. Images are **not** generated by the build — capture them after `npm run start` at http://localhost:4173/chores.

Minimum recommended set for acceptance:

- `01-home-full.png`
- `02-dashboard-full.png`
- `03-schedule-assign.png`
- `03-users-full.png`
- `00-chores-edit-modal.png`
